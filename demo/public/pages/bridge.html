跨 iframe 调用

这个页面跑在 iframe 里，与站点容器是两个文档。它不加载 vue / pinia / element-plus，只发一条消息就能指挥容器开页签、查菜单 —— 协议只有 method 和 payload 两个字段。 

// 最简：一行。不带 id，响应只能按 method 认领
window.parent.postMessage({ method: 'addTab', payload: { text: '报表中心', href: '/pages/reports.html' } }, '*')

// 带上 id，容器会原样回填 —— 并发请求可以按 id 精确配对
window.parent.postMessage({ method: 'queryMenu', payload: { name: '订单管理' }, id: 'my-1' }, '*')

// 容器配了 bridge.origins 时，第二参换成容器 origin
window.parent.postMessage({ method: 'closeTab', id: 'my-2' }, 'https://container.example.com')

// 收响应
window.addEventListener('message', (e) => {
  if (!e.data || typeof e.data.ok !== 'boolean') return
  console.log(e.data.id, e.data.method, e.data.result, e.data.error)
})
